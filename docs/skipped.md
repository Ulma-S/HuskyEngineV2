# 理解をスキップした範囲

後で振り返るための記録。CLAUDE.md の学習方針 4 に基づく。

## M0 ステップ1: CMake で空のプロジェクトを作る(2026-11-11)

理解できた: `build/` の中身は生成物で、消すと exe や .obj が失われる。

スキップした確認(「今回の本質ではない」として):
- `cmake --preset`(生成)と `cmake --build`(ビルド)が別の段階であること
- ソースやヘッダの追加は `CMakeLists.txt` の `add_executable` に書く。VS で `.vcxproj` に足しても、次の生成で上書きされて消える
- `/EHsc` を取り除いてから `/EHs-c-` を付ける理由(付けるだけだと、矛盾した指定が両方渡り、上書きの警告 D9025 が出る)

## M0 ステップ2: SDL3 を FetchContent で組み込む(2026-11-11)

理解できた: `target_link_libraries` を消すとビルドが通らない(ただし失敗するのはリンクより手前のコンパイルで、`SDL3/SDL.h` が見つからないため)。

スキップした確認:
- FetchContent は生成(configure)のときに SDL3 のソースを `build/_deps/` にダウンロードし、自分のプロジェクトの一部としてビルドする。NuGet と同じく「バージョンを書けば取ってきてくれる」が、ビルド済みのバイナリではなくソースを取ってきて手元でビルドする点が違う
- `target_link_libraries` は、ヘッダのインクルードパスとライブラリのリンクを、まとめて伝える
